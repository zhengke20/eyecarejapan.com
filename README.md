# Eyecare Japan (eyecarejapan.com)

日本で買えるメガネ・コンタクトのブランド・お店・新作まとめ。個人プロジェクト(M2IEとは無関係)。
業界ポータルの共通フレームの1つ目の業界でもある。

## ファイル

| ファイル | 役割 | 業界ごとに変える？ |
|---|---|---|
| `index.html` | 外枠(ヘッダー・本文・ダイアログ)とSEO用meta | タイトル・説明・URLだけ |
| `portal.css` | 見た目(白黒、色は小さな丸だけ) | 変えない |
| `portal.js` | 共通エンジン(トップ / ブランド / お店 / 新作 / ブランド詳情 / 四語切替) | 変えない |
| `site.js` | 業界の設定: セクション、トップの「さがす」、注目ブランド、丸の色、文言(四語) | 変える |
| `data.js` | 業界のデータ: brands / shops / news | 変える |

## 新しい業界をつくる手順

1. このフォルダをコピーし、新しい名前にする。
2. `site.js` を書き換える。
   - `sections`: ヘッダーの切り替え(例: メガネ｜コンタクト)。各セクションに brands / shops / news のどれを出すか。
   - `home.cats`: トップの「さがす」タイル。`[ラベル, セクション, タブ, {t:'種別'}]`。
   - `home.featured`: トップに並べるブランド名。
   - `dots`: 種別ごとの丸の色。
   - `text`: 画面の文言と、種別・業態・特徴(`f_xxx`)のラベル。四語で書く。
3. `data.js` を書き換える(書式は下)。
4. `index.html` の `<title>`・description・canonical・og を差し替え、`CNAME`・`robots.txt`・`sitemap.xml` のドメインを変える。

## データの書式

- **brands**: `n` 名前、`sec` セクション、`t` 種別、`c` 国、`p` 価格帯 1〜4、`w` 主な購入先(`own` 直営など)、`u` 公式URL、`m` メーカー
- **shops**: `n` 店名、`sec`、`t` 業態、`s` 店舗数(括弧内は時点)、`f` 特徴キー、`u` URL、`only` この種別のブランドだけ扱う店
- **news**: `d` 日付、`sec`、`b` ブランド名、`k` 区分、`s` 出典URL、`v` 要確認、`x` 内容 `{ja,zh,en,ko}`

ブランド詳情の「買える場所」は、`w` があればその購入先(直営なら同名の店舗数も表示)、なければ同じセクションのお店一覧。
「本サイトで購入(準備中)」ボタンは、購入機能の置き場所として残している。
